# Security

Report suspected vulnerabilities privately to **hello@morrowdock.app**.
Do not put credentials, private materials, learner data, or exploit payloads
containing personal data in a public issue. Include a synthetic reproduction,
affected version, and expected and observed behavior.

This is an early preview with a draft contract. The local mock is for synthetic
tests only and is not a production relay. Schema validation does not establish
source authority, privacy, or safe rendering. Treat all content as untrusted.
